Questions
FAQ
どうやって購入しますか？
+
こちらのページでウォレットを接続し、対応通貨で決済することでHYKをご購入いただけます。
どのウォレットに対応していますか？
+
MetaMaskをはじめとする主要ウォレットに対応予定です。詳細な対応ウォレットは購入画面をご確認ください。
どの通貨で購入できますか？
+
USDT、BNBで購入可能です。
プレセール価格はいくらですか？
+
プレセール価格は 0.015 USDT です。
最低購入額・最大購入額はありますか？
+
最低購入額は10 USDT相当です。最大購入額に上限はありません。
どのネットワークを使えばいいですか？
+
BEP-20ネットワークでの購入となります。購入前に、接続しているネットワークをご確認ください。
購入後、HYKはすぐに受け取れますか？
+
購入後は、当サイトのマイページにて購入数量をご確認いただけます。HYKは所定のロック期間終了後、段階的に受け取り可能となります。受け取り可能分は、マイページ上でClaimすることでウォレットに反映されます。
購入履歴はどこで確認できますか？
+
購入後に表示されるマイページにて、購入履歴および保有数量をご確認いただけます。
ロックとベスティングとは何ですか？
+
ロックとは、購入後すぐには受け取れず、一定期間引き出しできない状態を指します。ベスティングとは、その後にトークンが一度にすべてではなく、一定期間にわたって段階的に受け取れる仕組みです。
いつから受け取り開始になりますか？
+
2026年8月1日より、段階的に受け取り開始となる予定です。
Claimには期限がありますか？
+
現時点では、Claimに期限は設けておりません。受け取り可能になったHYKは、マイページからご確認・Claimいただけます。
受け取り方法はどうなりますか？
+
マイページにて受け取り可能数量をご確認いただけます。受け取り可能分は、「Claim」ボタンを押すことで接続中のウォレットに反映されます。
間違ったネットワークで送った場合はどうなりますか？
+
対応外ネットワークで送金された場合、正常に購入が反映されない可能性があります。送金前に、必ず対応ネットワークと通貨をご確認ください。なお、状況によっては復旧や返還ができない場合があります。
購入後のキャンセルや返金はできますか？
+
購入後のキャンセル・返金は原則として受け付けておりません。内容をよくご確認のうえ、ご購入ください。
購入時に本人確認は必要ですか？
+
購入時の本人確認（KYC）は不要です。対応ウォレットを接続することでご参加いただけます。
ガス代や手数料はかかりますか？
+
ご購入時およびClaim時には、ブロックチェーン上のガス代が別途発生する場合があります。ガス代はネットワーク混雑状況により変動します。
ウォレット接続は安全ですか？
+
ウォレット接続は、購入手続きのためにお客様ご自身のウォレットを連携する仕組みです。当サイトが秘密鍵やシードフレーズをお伺いすることはありません。安全のため、必ず公式サイトURLをご確認のうえご利用ください。
サポートが必要な場合はどこに連絡すればいいですか？
+
専用Telegramサポート窓口を設置予定です。詳細は公式案内をご確認ください。
HYKとは何ですか？
+
HYKは、HIYOKOエコシステム内で活用される基軸トークンです。ゲームや健康行動など、複数の体験導線とつながる設計が特徴です。
HYKは上場予定がありますか？
+
現時点で、HYKは上場を予定しています。詳細な時期や取引所については、決まり次第あらためてご案内いたします。
CheePointとは何ですか？
+
CheePointは、ゲームプレイや健康行動などの体験によって貯まるポイントです。貯まったCheePointは、条件に応じてHYKへ交換できる仕組みを想定しています。
Vitalisとは何ですか？
+
Vitalisは、AI虹彩認証を活用した健康管理デバイス＆アプリです。ユーザーの健康行動を可視化し、その行動をCheePointへつなげる入口として機能します。
HYKは何に使えますか？
+
HYKは、CheePointとの交換導線を通じて、HIYOKOエコシステム内の利用価値と接続される設計です。CheePointは、将来的にゲーム内のさまざまな利用シーンへの展開が予定されています。
なぜCheePointとHYKを分けているのですか？
+
CheePointは日常の体験や行動を蓄積するためのポイント、HYKは価値流通を担うトークンとして役割を分けています。これにより、ユーザー体験とトークン設計を切り分けながら、エコシステム全体の循環を目指しています。
HYKの価値設計はどうなっていますか？
+
HYKは、単体で完結するトークンではなく、ゲーム・健康行動・ポイント蓄積・交換導線と接続されたエコシステムの中で価値が設計されています。ユーザーの行動によってCheePointが蓄積され、その先の交換先としてHYKが位置づけられることで、利用導線と価値流通の両面を持つ構造を目指しています。
公式情報はどこで確認できますか？
+
最新情報は、公式SNSおよび公式コミュニティにてご確認いただけます。重要なお知らせも順次そちらでご案内いたします。
